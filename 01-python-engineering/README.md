# 01 — Python Engineering

This milestone turns Python from a reading/debugging language into a project-building tool.

## Goal

Build clean, runnable Python modules that can be used inside AI services and edge-system workflows.

## Topics

- project structure
- functions and modules
- type hints
- dataclasses
- exceptions
- logging
- pathlib
- argparse / CLI scripts
- pytest basics
- requirements.txt / pyproject.toml

## Output

Small scripts and modules that can be run, tested, logged, and reused.
