# 08 — AI Systems Architecture

This milestone connects individual AI components into a complete physical-world system.

## Goal

Design system loops where perception, state, planning, action, monitoring, and recovery work together.

## Topics

- perception
- state estimation
- planning
- action
- feedback loops
- sensor fusion thinking
- fail-safe logic
- human override
- monitoring
- recovery after failure
- offline-first architecture
- physical-world automation

## Output

Architecture notes and small prototypes that show how AI modules connect to sensors, services, devices, and actions.
